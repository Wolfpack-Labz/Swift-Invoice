# Wolfpack Labs Header Notes

The header/logo/menu now uses the same structure on every HTML page.

## Shared header styles

Edit this file for global header/menu updates:

```text
styles/shared.css
```

The reusable classes are:

```text
.topbar
.brand
.brand-logo
.nav
```

## Header links


All other pages use links back to the homepage sections:

