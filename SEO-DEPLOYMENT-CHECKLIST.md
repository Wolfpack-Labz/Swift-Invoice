# Wolfpack Labs SEO Deployment Checklist

Updated: July 23, 2026

## Deploy

1. Replace the current GitHub Pages files with the contents of this folder.
2. Confirm the custom domain remains `wolfpack-labs.com` and HTTPS is enforced.
3. Open the homepage and the three new acquisition pages:
   - `/invoice-app-for-contractors.html`
   - `/invoice-app-for-freelancers.html`
   - `/invoice-vs-estimate.html`
4. Confirm the launch form still submits successfully.

## Google Search Console

1. Inspect and request indexing for the homepage and each new acquisition page.
2. Resubmit `https://wolfpack-labs.com/sitemap.xml`.
3. Check Page Indexing, Core Web Vitals, Enhancements, and Manual Actions.
4. Review search queries after enough data is collected. Improve pages based on real impressions and click-through rate rather than adding many near-duplicate keyword pages.

## Bing Webmaster Tools

1. Import the verified Google Search Console property or verify the domain directly.
2. Submit `https://wolfpack-labs.com/sitemap.xml`.
3. Submit the homepage and three new acquisition URLs using URL Submission.
4. Consider IndexNow after the site is stable and a Bing key has been created.

## Ongoing acquisition

- Publish first-hand product guides, release notes, and workflow examples that demonstrate how Swift Invoice solves real contractor and freelancer problems.
- Earn relevant links and mentions from contractor, freelancer, small-business, and local-business communities. Avoid paid link schemes.
- Add App Store links and verified app details to the SoftwareApplication structured data after launch.
- Add genuine ratings or reviews only after they exist; never fabricate structured-data values.
- Track conversions from organic traffic to the launch list and, after release, to App Store visits.
